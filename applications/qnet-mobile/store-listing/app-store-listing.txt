DESCRIPTION (4000 chars max)
====================
QNet Wallet is a non-custodial wallet for the QNet network. Keys are created on your device and never leave it. The app has no accounts, no analytics and no tracking, and works the same on iPhone and iPad.

WALLET
• Create a wallet or restore one from a 12- or 24-word recovery phrase
• Send and receive QNC and QNet tokens, and SOL and 1DEV from the wallet's Solana address (Solana devnet test tokens); show a QR code of your address, or scan an address or a Solana payment request to fill in the Send form
• Transaction history that outlives node pruning; each confirmed QNet transaction opens in the block explorer, and the SOL and 1DEV sends made on this device are listed too
• History split by network, QNet and Solana, under a header for each day
• Unlocks with Face ID, Touch ID or the device passcode, or with a password on a device without one
• A built-in web browser to use websites with the wallet: every connection, message signature, send and contract call is shown and confirmed in the app first

LIGHT NODE (OPTIONAL)
A QNet light node is registered to a wallet on the QNet network. If the network lists one for your wallet, the Node tab shows it and this device can run it: about once every four hours the network sends a short signed status request, and the app answers with one ML-DSA-65 signature. This is not mining: no hashing, no proof-of-work, and blocks are produced by server nodes. The Node tab shows whether the node answered this epoch, how many epochs the network counted, and the node balance, which you can move into your wallet with an ordinary transaction. You can stop at any time. A wallet's super node runs on a server; the Node tab shows its status, epochs and node balance. The app sells nothing and has no in-app purchases.

The node runs only on a device that passes the system's device check, one node per device. It runs on iPhone and iPad; it is not offered on Mac or Apple Vision Pro.

POST-QUANTUM CRYPTOGRAPHY
QNet transactions are signed on the device with ML-DSA-65 (NIST FIPS 204); SOL and 1DEV transfers are signed on the device with the wallet's Solana key (Ed25519).

OPEN SOURCE
The app is open source under Apache-2.0, in one public repository with the rest of QNet; the node is source-available under the Business Source License 1.1.

LANGUAGES
English, Chinese (Simplified), Russian, Spanish, French, German, Japanese, Korean, Portuguese, Arabic and Italian.

GOOD TO KNOW
• QNet is an experimental network at the testnet stage. QNC has no market value. SOL and 1DEV in the app are Solana devnet test tokens with no market value either. Any node balance is set by the network protocol, is not guaranteed and is not paid by Orrery Group LLC.
• Your recovery phrase is the only backup. Nobody can recover it for you.
• The system decides when an app may run in the background, so some epochs can be missed; an app closed from the app switcher, or not opened since the phone restarted, answers again when it is opened: https://aiqnet.io/support?from=app

====================
APP REVIEW INFORMATION — NOTES (paste into App Store Connect; the sign-in section stays empty, there is no account)
====================
QNet Wallet is a non-custodial wallet for the QNet test network (QNC has no market value) by Orrery Group LLC; it also sends SOL and 1DEV (Solana devnet test tokens). No sign-in or account; Face ID, Touch ID or passcode unlocks a wallet made from a recovery phrase.

NODE TAB. The open wallet's node as the network records it: none (text only); a light node on this device (status, balance, Move to wallet), on another device or on none (Use this device); a super node on its server, only shown (status, last seen, epochs, balance, Move to wallet). Only on aiqnet.io: one line. A linked light node answers the network's status request about once per four-hour epoch with one ML-DSA-65 signature: no hashing, no proof-of-work; server nodes produce blocks. The wallet works fully without a node.

WHERE A NODE COMES FROM. One per wallet, made outside this app. For a light node, on aiqnet.io in a browser, the website burns 1DEV test tokens from a one-time address it creates, funded from the user's Solana wallet, possibly this app with an ordinary SOL and 1DEV send. Burned tokens go to nobody, Orrery Group LLC included. A super node is registered with the QNet browser extension on a computer and runs on the user's own server with the QNet node software; the app only shows it. The app has no receipt code, burn or code entry, or link to aiqnet.io's node page; its browser does not open it.

REQUESTS FROM THE WEBSITE. Five sheets no button or menu inside the app opens: only a verified universal link on link.aiqnet.io, each confirmed with Face ID, Touch ID or passcode: (1) "Share this wallet's addresses"; (2) "Set up a light node for this wallet": the wallet signs that the website may prepare a light node for it with a one-time address the website then makes (no funds leave the wallet); (3) "Link this wallet's node to this device": the wallet signs its own consent to its node's registration (if still pending) and binds this device's answer key and push channel; (4) "Move node balance to this wallet"; (5) "Unlink this wallet's node from this device". The app signs nothing for another wallet and never burns or buys anything.

DEVICE CHECK. Light nodes run only on a physical iPhone or iPad; when one is linked the app uses Apple's App Attest and DeviceCheck (no prompt, no tracking) so that one device runs one node; the link sheet and "Use this device" disclose it before Confirm; the wallet is never checked. A demo node moves to a review device at once (in four hours if it ran this app's node before).

NODE BALANCE. Each epoch the protocol splits its issuance among the nodes that answered its status request, in the background or when the app is opened. Move to wallet claims it in an ordinary transaction; not a payment from Orrery Group LLC, not guaranteed. The app offers nothing for downloads, referrals, posts, reviews or any promotional action.

====================
EXPORT COMPLIANCE (App Store Connect's encryption questions, not the notes)
====================
Encryption: ML-DSA-65 signatures, Ed25519 signatures (Solana transfers), SHA-3/SHAKE, X25519 with HKDF-SHA256 and
AES-256-GCM (the encrypted answers to aiqnet.io's requests), PBKDF2-SHA256 with AES-256-GCM (keys at rest) — standard
algorithms (NIST FIPS 204/202/197, RFC 7748/8032/5869/8018) implemented in the app, not proprietary ones; the device key
of App Attest is Apple's. ITSAppUsesNonExemptEncryption is set to YES (store-listing/README.md, "Export compliance").
